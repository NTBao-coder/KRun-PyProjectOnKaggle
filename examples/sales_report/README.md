# Sales report demo

The maintained template now lives in
[krun/demo_templates/sales_report](../../krun/demo_templates/sales_report/README.md)
so it ships with the Python package. Create a writable copy with:

```bash
krun demo sales-report --copy-only
```

Existing results in this directory remain untouched. Use
`krun status --project examples/sales_report` to inspect previously created jobs.
